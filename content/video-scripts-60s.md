# CSI Group website videos: 60 seconds or less

Eight videos, each 60 seconds or shorter, for the pages that matter most or need the most explanation. Each one lists the page it plays on, the file name to save it as, the length, the shots, and the spoken script. Spoken scripts are written for about 2.3 words per second, so a 60-second script is 135 words or fewer.

**How to add a finished video:** save the MP4 in `public/videos/` with the file name shown, optionally add a poster image with the same name ending in `.jpg`, then rebuild. A video appears on its page only when its file exists, so nothing shows as empty in the meantime.

**Brand rules for every video:** blue only (navy `#1E3A5F`, light blue `#4A9FD4`, white). Georgia for on-screen titles, Montserrat for small captions. No em dashes in captions. Never "seamlessly" or "journey". End on the CSI Group® logo and "From Taxes to Retirement, Let Our Family Guide Yours.®". Show **(877) 4-CSI360** and csicpa.com in the last 3 seconds.

**Compliance:** any video that mentions investments or advisors needs the full approved LPL disclosure block from the website footer in the end card. Have compliance review every script before posting. Names such as Dana, Rob, Anita, Jordan and Tasha are stand-ins; replace them with real team members when you film.

**Pricing:** the earlier scripts mentioned a price for new families. These versions leave it out, because the site's own rules say not to show dollar figures and the home page currently shows one. Decide which message you want, then add it back in if needed.

**Videos already on csicpa.com (now embedded on the new site):**
- "CSI About Us" (YouTube) plays on the About page, in the slot for video 8. The new Brooklyn 1973 script (video 8) is optional.
- "Tax Topic: Trusts" (YouTube) plays on the Wills & Estate Planning service page, in the slot for video 4. The new estate script (video 4) is optional.
- To use your own files instead, save an MP4 with the slot's file name in `public/videos/`. A file there takes the place of the embed only if you remove that slot's entry from `content/embeds.json`.

## Style block (paste before every brief)

Create a photorealistic, documentary-style video for a family-owned financial services firm in New Jersey. Real middle-class families and advisors, natural and unposed, warm natural light, lived-in suburban homes and bright modest offices, never luxury interiors or skyscrapers. Steady handheld or slow gimbal moves, shallow depth of field, 24 fps, 16:9, 1080p or higher. Color grade slightly warm with muted blues in the background. Soft acoustic or piano score, low in the mix. Clean, well-paced voiceover in a warm, plain, confident voice, like a trusted family advisor at the kitchen table, never a salesman. On-screen text is minimal: short titles in a serif font, navy or white, with a thin light-blue rule. Shots of 4 seconds or longer. No stock-footage feel, no cheesy smiles, no text overlays other than the ones specified, no logos other than the end card described.

## Production notes

- Generate the hero loop without voiceover first. It must read with the sound off.
- Keep talking-head shots at a slight angle with the subject left of center, so text can sit on the right.
- Ask for 4-second shot lengths or longer. Fast cuts feel like advertising, not a family firm.
- Add captions (a WebVTT file) before publishing, so the videos work with the sound off and for deaf and hard-of-hearing visitors.
- When you film the real team and co-CEOs, reuse these scripts and shot lists so the AI versions can be swapped one for one.
